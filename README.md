# CyberCmd Hub

Un répertoire de commandes Linux utilisées en cybersécurité (pentest, hacking éthique, CTF), avec pour chacune une explication claire de son rôle, son niveau de discrétion et sa catégorie.

**Site en ligne : [TON-URL-NETLIFY-ICI](https://cybercmd-hub.netlify.app/)**

## Pourquoi ce projet

Quand on est en intervention et qu'on a besoin de se souvenir rapidement d'une commande et de son usage exact, CyberCmd Hub centralise ça en un seul endroit, avec une recherche et des filtres par catégorie plutôt que de fouiller dans plusieurs cheat sheets éparpillées.

## Fonctionnalités

- Recherche instantanée par nom de commande ou mot-clé
- Filtrage par catégorie (Reconnaissance, Réseau, Web, Exploitation, Escalade de privilèges, Post-exploitation, Forensics, OSINT, Anonymisation...)
- Indication du niveau de risque de chaque commande (discret / bruyant)
- Interface responsive, utilisable sur mobile en intervention

## Technologies utilisées

- HTML / CSS / JavaScript natifs (aucun framework)
- Données stockées dans un fichier JSON
- Déployé sur Netlify, connecté à GitHub pour un déploiement automatique
