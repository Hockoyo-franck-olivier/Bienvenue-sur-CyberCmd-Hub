Bienvenue sur CyberCmd Hub

Reconnaissance Discret

whois exemple.com

Récupère les informations d'enregistrement d'un nom de domaine : propriétaire, dates de création, serveurs DNS.

Réseau Bruyant

nmap -sV -p- 192.168.1.1

Scanne tous les ports d'une machine et identifie les services actifs.

Escalade de privilèges Discret

sudo -l

Liste les commandes que l'utilisateur actuel peut exécuter en tant qu'administrateur (sudo).
